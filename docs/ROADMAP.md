# 开发路线图

完整首版目标仍是全天记忆与主动口述一起工作。浏览器原型确认的是体验方向；当前原生只完成录音、同步队列、ASR 契约和留存基础，不能把原型示例数据视为已接入能力。下列顺序是开发建议，可按实机反馈调整。

## 当前基础与收尾

- 核心 33 项测试通过；手机 / Watch SDK 签名构建通过，Watch App 已嵌入手机产物。
- 手机已安装、信任、启动，取得可读 m4a 和完整 manifest；用户确认回听正常。
- S9 / watchOS 27.0 已安装启动；首次短录传到手机且只导入一次，手机回执后 Watch 释放音频副本。
- 已实现 Watch 轻点 Bot 连续录音开停、实际计时、重点/日记起点标记及手机详情展示；标记持久化与同步契约测试通过，真实手势和全天运行继续验收。
- 优先补齐真实 ASR、配对 Watch 的离线传输与后台多轮回执、跨分段边界缺口、锁屏长录、来电/路由切换、重启恢复及电量/容量测量，见 [验收表](ACCEPTANCE.md)。
- 三主题、暖纸底和中文字体已在 iPhone 模拟器及真机确认；Watch 已改为一屏 Bot 主按钮，新增日记选择、取消和呼吸动效。早期一屏版有 S9 画面证据，当前版以用户实测继续验收；系统双指互点已接入，但尚未完成实体手势验证，辅助字号与小屏适配也待测。

诊断工具已支持有界自动采样与离线报告；后台配置热修后取得多段五分钟录音，具体覆盖条件和文件验证见验收记录。iPhone 新增底部 Bot 主操作与连续录音分组，真实健康数据、记忆聊天和周/月视图仍未接入。

## 下一批功能

| 工作面 | 目标 | 完成边界 |
| --- | --- | --- |
| 主动口述与持续采集 | 主动入口优先，停止后自动保存/返回；在长录中标记主动区间 | 录音、指令区间与执行结果有稳定 ID；中断/离线清楚反馈 |
| 本人声纹与说话人 | 全天记录可标注本人／其他／不确定；按时间对齐到原文 | 自愿登记、可删除参考声纹；专用模型匹配，低置信度不强行归属；不依赖文本 LLM 猜身份 |
| Watch 长录与标记验收 | 实测轻点连续录音开停、长按标记、分段时间坐标与跨端显示 | 锁屏/中断/重连不丢片段和标记；系统双指互点只映射当前主动作；不承诺后台全局手势 |
| Apple 提醒事项 | 任一端修改标题、到期、完成状态，另一端同步 | EventKit 权限、记录映射、变化后重读、冲突与重试；明确口述提醒直接执行，被动提取先确认 |
| Obsidian | 日记、选题与自动每日回顾写入用户选定 vault | 文件夹授权、可达性、幂等写入及失败重试；分享文字不等于已归档 |
| 两轮转写与文本 AI | 快转提供初稿，精转改善正式文本；通用接口可各自选择服务 | 独立配置/密钥边界、任务状态、文本版本与来源；当前单 ASR 不等于两轮已实现 |
| 环境声音 | 手机低优先级识别键盘、交通等背景线索 | 独立于 ASR、低置信度保留未知；不能从声音推断用户行为或情绪；先测增量能耗 |
| 健康、地点与回顾 | 主要时间线直接展示身体/地点线索，回顾结合运动与睡眠 | 权限与来源时间可见；睡眠总时长/深睡比例可追溯，Apple 睡眠评分仍需确认可读接口与实机接入 |
| 记忆问答 | 搜索、AI 问答和每日回顾自动保存 | 回答能链接到录音片段/原话/时间；原声清理后仍引用文字，不显示可播放假入口 |
| 可替换 Agent | 任务卡选择执行目标并真正交接 | 统一 `taskId / dispatch / receipt` 适配接口；分别记录已接收、执行中、已完成与失败，不以复制或 HTTP 成功代替完成 |

## 数据与维护原则

保留用户选择的原声天数、长期文字和显式保留例外；正式转写尚未持久保存时暂缓清理。未来精转要明确哪一版本满足正式保存条件；云临时副本按服务留存协议清理。当前默认 30 天与配置能力以 [架构](ARCHITECTURE.md) 为准。

扩大能力时沿用「先落盘，再报告成功」：同步收到文件、Obsidian 写入、提醒保存、Agent 接收和 Agent 完成都需各自回执。先做稳定的本机闭环，再决定是否增加 Mac / NAS 精转服务；它目前是可选设计，没有服务正在运行。

2026-10-13 的声纹、后端能力和 Watch 交互设计见 [全天记录方案](ALL_DAY_RECORDING.md)。除已标明接入的主动口述主动作外，其余方案尚未实现，不计入已通过验收。
