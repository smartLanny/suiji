# 已确认的设计基线

采用前期方案 2 的温暖、克制风格，保留 iOS 原生导航、表单、玻璃工具栏和底部导航。标题有纸质笔记的感觉，内容清晰，角色简约。原生实现不能用系统太阳、叶子符号替代已经确认的角色。

## 交互准则

- 主页是以现在为中心的连续时间线。条目以 24 小时时间和内容为主，处理状态次要；没有正式摘要时不重复展示截断标题与相同正文；睡眠、运动将作为真实独立事件接入。
- 主要入口始终是“说一句”。点一次开始，点停止即保存，回到原浏览位置；没有第二次“完成”页。保存、同步和转写分别呈现真实状态。
- Watch 首页以大 Bot 为主体，不滚动、不常驻“点我说一句”或同步说明。新用户首次进入短暂提示；底部只保留小录音图标；未开启配“全天”，全天开启配计时，快速口述配类型与计时，异常时显示“已停止”，保存/取消/标记短暂反馈。更多入口收纳日记、最近记录和主题。
- 未开全天时，点 Bot 开始随记，再点停止保存。按住后拖左选随记、拖右选日记，松手才开始，中央松手取消选择；快速口述中下拉预览“松手取消”，拖回继续。只允许丢弃尚未提交的首段，已保存的长录分段保留；此时仍可正常停止保存。
- 全天记录由底部状态按钮独立开启/停止，显示真实计时。全天开启后轻点 Bot 只标记此刻；按住拖左停止、拖右标记日记起点，中央松手取消选择。标记持久化成功才反馈，不开启第二个录音器，不把标记称为已生成日记。
- Watch 系统双指互点复用 Bot 当前主动作：快速口述开停或全天标记。启动准备或展示更多页时禁用；手势选择由触屏统一处理。手势不替代可访问按钮，实体系统手势仍需单独验收。
- 切换今天、记忆、待处理保留浏览上下文。待处理只承载未完成或需要处理的真实记录，成功内容自动归入时间线。
- 配置成功自动收起，不用成功弹窗让人再确认；错误留在当前上下文，可重试。缩短留存且即将删除原声时明确显示条数。
- 回听、保留原声、更正文字在记录详情直接可达。正在录音时不允许回听抢占麦克风会话。
- 原型中的健康、日/周/月回顾、语音查询/指代更正、提醒和 Agent 完整流程仍属后续接入范围；使用真实数据前不填假结果。

## 已授权产品方向

完整原型中的日/周/月切换位于日期栏；月回顾连接选题进度、重要记录、睡眠/运动趋势与原文。提醒事项双向同步，Obsidian 是归档目的地，Agent 可更换执行方式。这些已确认方向应延续，具体原生接入进度以 `ROADMAP.md` 为准。

## Watch 角色动效

主角色按 sprite 的可见轮廓居中，并按三主题待命/倾听轮廓的共同边界适配 Bot 区域，预留呼吸与电平缩放余量。待命时约 4.2 秒一轮轻呼吸、微浮动，墨点低频眨眼；录音电平响应继续保留。最多 15 fps，仅前台且 Timeline 为 live cadence 时运动；息屏、减少动态效果或触摸时停止闲置运动。角色动画不改变按钮命中区。素材不重绘，手机默认展示不受 Watch 居中修正影响。
