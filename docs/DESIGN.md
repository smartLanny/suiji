# 已确认的设计基线

采用前期方案 2 的温暖、克制风格，保留 iOS 原生导航、表单、玻璃工具栏和底部导航。标题有纸质笔记的感觉，内容清晰，角色简约。原生实现不能用系统太阳、叶子符号替代已经确认的角色。

## 交互准则

- 主页是以现在为中心的连续时间线。条目以 24 小时时间和内容为主，处理状态次要；没有正式摘要时不重复展示截断标题与相同正文；睡眠、运动将作为真实独立事件接入。
- 主要入口始终是“说一句”。点一次开始，点停止即保存，回到原浏览位置；没有第二次“完成”页。保存、同步和转写分别呈现真实状态。
- 切换今天、记忆、待处理保留浏览上下文。待处理只承载未完成或需要处理的真实记录，成功内容自动归入时间线。
- 配置成功自动收起，不用成功弹窗让人再确认；错误留在当前上下文，可重试。缩短留存且即将删除原声时明确显示条数。
- 回听、保留原声、更正文字在记录详情直接可达。正在录音时不允许回听抢占麦克风会话。
- 原型中的健康、日/周/月回顾、语音查询/指代更正、提醒和 Agent 完整流程仍属后续接入范围；使用真实数据前不填假结果。

## 已授权产品方向

完整原型中的日/周/月切换位于日期栏；月回顾连接选题进度、重要记录、睡眠/运动趋势与原文。提醒事项双向同步，Obsidian 是归档目的地，Agent 可更换执行方式。这些已确认方向应延续，具体原生接入进度以 `ROADMAP.md` 为准。
