# 验收记录

截至 2026-10-12。环境：iPhone Air / iOS 27.0.1、Xcode 27 beta 4；目标设备含 Apple Watch S9。本文区分构建、测试、设备证据与用户反馈，后续更新请附日期及实际观察，不从界面状态推定后台任务完成。

## 已有证据

| 项目 | 结果与证据 | 仍未证明 |
| --- | --- | --- |
| 核心逻辑 | 22 项 SwiftPM 测试通过：持久化/恢复、重复导入、异常文件、回执保护、留存、mock HTTP/multipart | 系统录音、实际网络服务、Watch 实机传输 |
| 工程与签名 | 手机和 Watch 设备 SDK signed build 成功；Watch App 嵌入手机 bundle | 配对 Watch 实际安装与运行 |
| 手机运行 | `com.lann.suiji` 已真机安装、信任、launch | 长时间运行、系统中断后恢复 |
| 手机短录保存 | 取回 m4a 与完整 manifest：`duration=6.5466s`，`byteCount=108810`，`source=phone`，`captureState=ready`，`transcriptionState=pending` | 长录分段完整性与实际全天容量 |
| 音频可读 | ffprobe：AAC、44,100 Hz、单声道；容器时长 6.5945 秒、108,810 字节、实测 132,001 bit/s；用户确认回听正常 | 录音器请求 64 kbps 不代表实际输出码率；不可据此宣称全天仅 0.69 GB |
| ASR | mock 已覆盖参数/头部/路径、非空成功、空结果、401/429 等 | 无真实 Key，尚未执行真实服务上传与中文质量验收 |
| 原生视觉 | 正在按已确认原型对齐主题/角色 | 最终视觉、实际 Watch 命中区和系统材质体验尚未通过 |

## 下一轮实机验收

| 场景 | 操作与通过标准 | 当前状态 |
| --- | --- | --- |
| 真实 ASR | 用户配置服务，录制明确中文；文字非空且与录音相符，重新打开仍在。错误地址/认证/断网保留原声，失败可重试，空 200 不显示成功 | 待测 |
| Watch 回执 | 配对设备录制；手机出现唯一记录、文件可回听、manifest 持久保存；仅收到手机回执后 Watch 释放副本 | 待测 |
| 离线与重传 | Watch 断连录制、重启、重连；离线显示待同步，记录不丢，重复传送不重复导入。记录实际到达时间，不承诺准点 | 待测 |
| 分段与锁屏 | 两端分别录制超过 10 分钟并锁屏；逐段核对音频时长、文件、manifest 和边界缺口；延长到全天后测容量、电量与温度 | 待测 |
| 中断与路由 | 来电、耳机断开、权限拒绝、音频服务重置；已有可读部分保留，停止/错误明确，不假装持续录音；手动恢复有效 | 待测 |
| 恢复与磁盘 | 在录音/转写中终止并重开；可恢复文件保留，队列可续跑，低空间停止有反馈。设备重启首次解锁前后检查文件/Keychain 可达性 | 待测 |
| 留存与回听 | 过期且正式文字已保存时清理音频；未转写/失败/显式保留例外不删；重开后文字仍在，已删音频不能播放。缩短天数时核对确认数量 | 核心测试通过，设备待测 |
| 视觉与低点击 | 三主题、原创角色、暖纸底、纸芽草绿，手机与 Watch 实际截图核对；录完无需第二次完成，错误/待处理/已保存状态可分辨 | 待最终验收 |

录音全天预算要用长片段实测文件大小与实际电量推导；此次约 6 秒片段只证明短录保存和回听。提醒事项、Obsidian、健康/位置、每日回顾、记忆问答和 Agent 交接尚未在当前原生版本实现，按 [路线图](ROADMAP.md) 开发后单独添加验收，不计入当前通过项。
